# CyberCardinals: reproducing KAIROS on StreamSpot

CIS 3370 Intrusion Detection Systems, Dr. Gonzalo D. Parra. Team: Jonas Halbrook, Emiliano Fears, Aaliyah Moorefield.

**The claim.** KAIROS (IEEE S&P 2024) reports, in Table 4 for the StreamSpot (Manzoor et al.) dataset,
TP=100 TN=375 FP=0 FN=0, with precision, recall, accuracy and AUC all 1.000, using 5 training graphs,
120 validation graphs and 475 test graphs with one time window per graph. We rebuilt the pipeline ourselves and try to get those numbers again.

## Reproduce it
```bash
bash scripts/setup_env.sh && conda activate kairos     # Python 3.9, torch 1.13.1 CPU, PyG 2.0.0
make reproduce                                         # data -> graphs -> stats -> baselines -> train -> evaluate -> compare
make reproduce QUICK=1                                 # shortened demo path (timings in results/env_report.txt)
make unit                                              # unit tests
```
`scripts/clean_checkout_test.sh` clones into an empty folder and runs the same command: use it on a machine that is not yours.
